# 社团活动信息收集系统

这是一个用于收集社团活动信息的网页前端应用。

## 功能特点

- 🎨 现代化的用户界面设计
- 📝 完整的表单验证
- 🎯 实时颜色预览
- 📱 响应式设计，支持移动设备
- 💾 数据收集和显示
- 🔍 控制台输出功能

## 数据模型字段

系统收集以下信息：

1. **社团名称** - 输入社团的名称
2. **活动内容** - 详细描述活动内容
3. **海报风格** - 选择海报的设计风格
4. **活动时间** - 设置活动的具体时间
5. **活动地点** - 输入活动举办地点
6. **主题色** - 选择活动主题颜色

## 使用方法

1. 在浏览器中打开 `index.html` 文件
2. 填写所有必填字段
3. 点击"提交信息"按钮
4. 查看页面上的结果显示
5. 打开浏览器控制台（F12）查看终端输出

## 文件结构

## 技术栈

- HTML5
- CSS3 (包含现代CSS特性)
- JavaScript (ES6+)
- 响应式设计
- 表单验证

## 浏览器兼容性

支持所有现代浏览器：
- Chrome
- Firefox
- Safari
- Edge

## 开发说明

- 所有表单字段都是必填的
- 颜色选择器提供实时预览
- 时间选择器默认设置为当前时间+1小时
- 提交后数据会同时显示在页面上和控制台中
